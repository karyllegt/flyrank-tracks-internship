# Project instructions

## Repository structure

- Keep each FlyRank track under `tracks/<track-name>`.
- Keep Frontend AI Engineering implementation code under `tracks/frontend-ai-engineering`.
- Keep track-specific notes and deliverables with the relevant track.

## Frontend conventions

- Use semantic HTML and accessible labels.
- Prefer small, composable JavaScript functions.
- Keep styling in track-local files unless it is shared by multiple tracks.
- Use clear, descriptive names and avoid unnecessary dependencies.

## Git conventions

- Use Conventional Commits, for example `feat: add assignment starter`.
- Keep commits focused and explain user-visible changes.
