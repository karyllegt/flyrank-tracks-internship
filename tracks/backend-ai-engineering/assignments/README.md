# Assignment evidence

This directory contains runnable, dependency-light evidence for every Backend AI Engineering assignment visible in the FlyRank portal. Each assignment has a focused README, implementation artifact, and verification notes. The implementations use Node.js standard-library primitives so reviewers can run them without a database server, API key, Docker daemon, or browser automation.
